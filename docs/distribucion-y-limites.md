# Distribución, derechos y límites

Este repositorio contiene documentación original y un script corto que modifica dos anclajes de Smali después de decodificar un APK. No incluye el juego ni su ejecutable, archivos de licencia o emulación, APK original o modificado, archivos OBB/PCK, partidas, driver Turnip, Lossless.dll, shaders, logs completos ni capturas del juego.

Resident Evil y sus marcas pertenecen a sus titulares. Este repositorio no afirma afiliación ni autorización comercial. Cada usuario es responsable de usar un APK y datos que tenga derecho a modificar, y de cumplir las licencias del port, del juego, de las herramientas y del generador de cuadros. La licencia de este repositorio cubre únicamente los documentos, diagrama y script originales aquí publicados.

La app LSFG-Android y su release mantienen sus propios términos. Lossless.dll es un componente de terceros que debe obtenerse legítimamente; no se copia a este proyecto. El driver V38 parcheado también permanece fuera del repo.

El método cambia el escalado del lienzo del APK. Llenar una pantalla con proporción distinta exige recortar una dimensión; no es posible mostrar el cuadro original completo, preservar proporción, evitar recorte y ocupar simultáneamente toda el área si las proporciones no coinciden. No estires la imagen para ocultar esa limitación.

La publicación documenta un caso de un dispositivo y una versión del port. No garantiza compatibilidad con otras versiones de APK, GPU, pantallas plegables, drivers, firmantes ni capas de compatibilidad.
