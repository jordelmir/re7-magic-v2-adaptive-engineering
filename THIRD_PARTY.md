# Componentes y marcas de terceros

Este proyecto no redistribuye componentes de terceros. Los nombres se mencionan solo para describir el caso técnico.

- Resident Evil 7 / Capcom: marca, juego y activos pertenecen a sus titulares.
- APK base y capa de compatibilidad: no incluidos; cada port conserva su propia licencia.
- Turnip V38 parcheado: no incluido.
- LSFG-Android: proyecto independiente con licencia propia; no incluido.
- Lossless.dll y shaders extraídos: no incluidos.
- Apktool, Android SDK Build Tools, ADB, FFmpeg y REA: herramientas externas sujetas a sus licencias.

Consulte la licencia y términos del componente original antes de modificar o distribuir cualquier APK.
